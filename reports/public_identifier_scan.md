# Public identifier scan

`NONESSENTIAL_SOURCE_IDENTIFIER_HITS = 0`

The publishable tree was scanned for course, training, instructor, institution, numbered lesson/chapter, local workspace, development-assistant and conversation identifiers. Scientific method names, package names and methodological references were retained.

The scanner's own pattern-definition source is excluded from content-hit counting; it contains the prohibited tokens only so that CI can detect them elsewhere.
