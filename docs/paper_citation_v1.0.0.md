## Methods software statement

The statistical analysis was executed using the *Target Trial Emulation Statistical Analysis Method Library*, version 1.0.0 (Zenodo: https://doi.org/10.5281/zenodo.21879884), through a production profile approved by the software's production registry.

## Reproducibility statement

The scientific analysis specification was frozen by the investigators before execution. The library validates researcher-prepared inputs and executes registered statistical profiles without changing the specification in response to observed results. Synthetic examples, input contracts, tests and validation summaries are publicly available; project-specific patient inputs are not distributed.
